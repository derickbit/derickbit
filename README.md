## Projetos em destaque

### Movimento Mariano Cenáculo

Plataforma desenvolvida voluntariamente para gestão de eventos,
inscrições, lista de espera, presença e galerias de fotos,
com painel administrativo autenticado.

**Tecnologias:** Next.js, TypeScript, PostgreSQL, Supabase,
Prisma, Cloudinary e Vercel.

[Conhecer a aplicação](https://mmcenaculo.vercel.app)

### CardNest

Plataforma web integrada a dois jogos de cartas desenvolvidos
em Unity: Hi-Lo e Blackjack. Inclui autenticação, perfis,
rankings e histórico de partidas, fóruns, chat com administrador, painel de atualizações (patch notes) e comunicação entre os jogos WebGL e uma API REST.

**Tecnologias:** React, Laravel/PHP, MySQL, Unity, C#,
WebGL e JavaScript.

[Conhecer a plataforma](https://card-nest.vercel.app)

### Retratos

Jogo autoral 2D top-down de terror publicado no itch.io.
Desenvolvi sistemas de diálogo, inventário, interação,
combate e comportamento de inimigos, além de câmeras
e cutscenes.

**Tecnologias:** Unity, C#, Physics2D, NavMesh,
Cinemachine e Timeline.

[Jogar no itch.io](https://derickbit.itch.io/projetoretratos)
· [Ver o repositório](https://github.com/derickbit/Retratos)
